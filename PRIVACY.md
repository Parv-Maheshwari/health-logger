# Privacy Policy for Health Logger

Last updated: 2026-11-27

Health Logger is a personal tool used by one person, its author, to write their own health
entries (nutrition totals, water intake and body weight) into their own Google Health account.

- **Data accessed.** With the user's consent through Google OAuth, the tool reads one private
  Google Sheet owned by the user and reads and writes nutrition, hydration and weight data in
  the user's own Google Health account.
- **Data storage.** Data moves directly between the user's spreadsheet and the user's Google
  Health account. The tool runs on the user's own computer. It stores OAuth tokens locally on
  that computer and nothing else. No data is sent to any other party or server.
- **Data sharing.** None. No data is sold, shared or used for advertising, analytics or any
  purpose other than the user's own logging.
- **Google API Services User Data Policy.** The tool's use of information received from Google
  APIs adheres to the Google API Services User Data Policy, including the Limited Use
  requirements.
- **Deletion.** The user can revoke the tool's access at any time at
  https://myaccount.google.com/permissions and delete local tokens by removing the tool's
  configuration folder.
