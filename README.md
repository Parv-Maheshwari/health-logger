# Health Logger

A personal, single-user command-line tool that copies my own food, water and weight entries
from a private spreadsheet into my own Google Health account through the Google Health API.

It is not a product or a service. There is no hosted component, no sign-up and no users other
than the author. The source is not published; this page exists because Google Cloud requires a
homepage for every OAuth app.
